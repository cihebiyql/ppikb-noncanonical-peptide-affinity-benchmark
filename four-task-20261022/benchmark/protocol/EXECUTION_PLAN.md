# 执行计划与验收

1. 只读核对四来源既有资源与实际标签，建立来源/化学身份/构建体/结构/原始测量关系；记录每任务可用数与缺口。
2. 冻结任务化输入。绝对亲和力按Kd/Ki/IC50区分；改动效应保留ΔpKd与ΔΔG各自符号/温度；实验二值与阈值派生分类分开；实验结构接触与预测结构代理分开。
3. 预先冻结来源/肽依赖、靶标相似关系分区，原始观测先分区后生成配对。任何外部集在调参前指定并核查跨库/公开权重暴露。
4. 登记八篇作者实现，在实际适用任务执行最小有效试跑与共同数据训练。不同任务适配如需改变输出头，单独命名；缺少训练代码/结构/标签时记实证缺口，继续其他通道。
5. 传统手工特征基线先行：回归Ridge/树模型、分类逻辑回归/树模型等；简单序列/PLM基线取已核验可用环境，不执行旧do_not_execute流程。训练/尺度拟合只使用train，validation选优，test不参与选择。
6. 每项使用种子0–9，保留所有超参数候选、逐样本预测、日志、权重、实际分母、seed级指标与mean±SD。固定测试拆分，随机种子不改变任务定义。
7. 独立重算适用指标：回归MAE/RMSE/Pearson/Spearman/R²；分类AUROC/AUPRC/MCC/F1/平衡准确率及校准；效应增加组内排序/方向；位点按复合物宏平均/PR指标、明确接触阈值和无肽结构可见性。单类/零方差指标写null。
8. 最终对账四来源×四任务×八方法，分别列成功、未就绪、不适用和运行失败。任务矩阵完整登记不等于所有训练已完成。
