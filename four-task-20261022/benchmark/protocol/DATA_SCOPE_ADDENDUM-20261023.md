# PPIKB当前范围的物种说明

当前9,116条PPIKB观测采用来源限定，并没有施加“只保留人源”的过滤条件。逐行回读原始`target_species`字段，6,581条原文明确标注`Homo sapiens`；其余2,535条保留各自的物种或其他来源标注，共95种不同的原始字符串。这里统计的是数据库提供的标签，不冒充独立序列分类认证。

例如，小鼠、大鼠、牛和酵母等来源记录仍在当前固定输入中。旧9,619条有效分子输入到9,116条的503条差异，来源原因表为490条明确病毒物种和13条明确命名毒素；没有因为一般记录为非人源而批量剔除。此前因蛋白名称子串而误排的39条记录已在scope_v2恢复。

本说明来自只读审计`reports/source-species-audit-v1/reported-species.json`，没有修改标签、序列、分区、训练规格或任何模型结果。旧来源原件与逐记录原因表继续保留。
