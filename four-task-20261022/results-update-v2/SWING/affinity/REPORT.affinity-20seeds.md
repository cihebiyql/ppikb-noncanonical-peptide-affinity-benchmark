每个原始 pKd 分区有 9,116 条观测；本方法接受其中 7,669 条原样二十种标准氨基酸字符串，含 7,120 条标准对照和 549 条带非标准化学注释的观测。后者的额外化学身份没有被序列骨架编码。其余观测仍保留在原数据库，模型未擅自替换非天然残基或去掉修饰标记。共同测试集合为先前冻结的 PepInter 可用观测交集（来源683、靶标946），可用于相同分母比较。

原作者的窗口编码和词袋构造函数按原 AST 使用，Doc2Vec 为 16 轮训练、72 维及 16 轮推理。表征只在训练集拟合，属于明确的严格归纳适配；XGBRegressor 是连续端点适配，并非 SWING 原论文的原生亲和力任务。本轮预声明调参网格为 200 棵树、深度 1/6、学习率 0.1，按验证 MAE 选择；它不同于作者 scv.py 默认分类读出的学习率 0.71。

四个已经启动的原 v2 实验保留原运行。仅后续尚未启动实验使用同模型内部重复输入缓存，键为完整有序 token 列表的 SHA 和训练种子，同时重放推理后随机状态。真实已训练模型的 TRAIN 输入检验确认每个 72 维向量、每次后续随机状态及模型参数 SHA 完全一致，训练轮次、数据和候选参数均未改变。该版本属于执行效率修订，不是新模型。完整 token 列表传给原生推理；Gensim 自身 10,000 token 的编译上限已在每条推理审计中记录。

外部 ProfAff162 含 112 条带实验标签的标准骨架和 50 条 PTM。两类分开评价，外部标签不参与调参。域级骨架、实际构建体、来源和同源关系仍需按数据审计解释，不能仅凭序列对不重叠称为完全独立的新家族验证。重复模型/种子预测没有增加独立实验观测数。

本报告只使用既有预测，新增拟合和模型前向均为零。科学结果齐全与本地大文件齐全分别记录；每个模型、sidecar、候选读出和日志的实际本地 SHA 验收名单见 status.interaction.continuation.v1.json 和逐种子 actual-local-SHA-audit，不从远端完成推断本地交付完成。
