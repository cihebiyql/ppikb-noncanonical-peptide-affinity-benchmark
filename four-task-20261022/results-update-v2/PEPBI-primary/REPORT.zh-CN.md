# PEPBI27条条件外测的原始来源核查

本轮对已经冻结并完成100个固定模型预测的全部27条候选补核原始论文，原CSV、标签、权重与预测保持原样。资格判断依据原图表与输入身份，未使用模型误差挑选样本。

|证据轴|实际核实数|解释|
|---|---:|---|
|原始文献明确的点值及单位|19/27|PTPA4、α-adaptin10、STAC5；数值核实与输入身份分别评价|
|与原文舍入值相容|2/27|α-adaptin的0.42/0.82 μM与图中0.4/0.8 μM相容，精确额外小数尚需补充表|
|原单元未闭合|6/27|Profilin4条未取得原ITC表；α-adaptin另有1条可能错肽、1条主图只报下界|
|测量温度|23/27|PTPA20°C、α-adaptin10°C、STAC25°C|
|原测量缓冲条件|9/27|PTPA4和STAC5；其他方法段不代替实际ITC条件|
|肽端基|4/27|PTPA图明确为自由N端和羧酸C端、未修饰序列|

**监督来源独立性与化学认证是两个轴。** 本次100个固定手工模型使用174维手工特征，没有蛋白语言模型预训练编码器。对其实际PPIKB训练来源核对，27条候选未发现精确输入对与原始ITC DOI重叠，可作为相对这些模型的监督来源分离条件验证。完整构建体、化学身份及全部测量上下文的认证仍逐项进行；“认证独立集0条”这一旧字段表示较强的全条件认证门，不能用全局PLM预训练未知否定这些手工模型已有的来源分离证据。该结论不自动转移给预训练模型，也不代表27个独立生物体系或新靶标家族。

PTPA的四个原始点值与当前记录一致，原图同时给出自由端基；标签来自20°C、去标签全长PTPA的ITC测量。其晶体结构采用另一截短构建体，结构来源与测量构建体分开记录。[原论文图1及方法](https://dr.ntu.edu.sg/server/api/core/bitstreams/3c65d8a1-0efd-4428-af75-b60ecc4d0ea9/content)

α-adaptin的三个输入存在额外F740D：原表第174行标G742D，实际输入含F740D/G742D；177、186行标G725E/G742D，输入还含F740D。另第178行的Eps15-P2/V800D=135 μM在主图相应单元为空，135显示于P1/V800D；第182行的167 μM在主图仅可核到>160 μM。补充表未取得，以上分别标为输入不一致或数值未闭合，未擅自换序列、改标签或把下界变为点值。[原论文图5](https://www2.mrc-lmb.cam.ac.uk/groups/hmm/publica/AP2Hub_EMBO2004/AP2Praefcke2004.pdf)

STAC5条的原补充表数值已通过通讯作者公开全文核对；三个STAC2输入与同篇PDB聚合物序列存在N端字母差异，晶体构建体不直接替代测量构建体。Profilin4条尚缺原测量表，已有PDB与摘要只支持部分序列背景。来源、失败响应和逐项未闭合字段见[STAC/Profilin审计](stac-profilin/REPORT.zh-CN.md)。

当前仍报告原27条全部预测及全部不利结果。本次没有重新训练、调参、推理或依据性能修整外测集；新增的`primary-context-index.csv/json`与逐来源侧车供后续评价分层使用，原外测主结果保持可追溯。
