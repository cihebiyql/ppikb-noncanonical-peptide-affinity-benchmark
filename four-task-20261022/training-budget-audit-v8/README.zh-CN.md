# 训练预算审计与首个验证敏感性结果

本增量核查原DTA共同基准300个候选的训练预算，并公开首个延长预算候选的验证结果。原150个选中模型／300个候选结果保持原样。本包是首例验收后的固定快照；其余12个候选尚未计入本包完成结果，后续进度另行发布。

原共同预算为**最多20轮、patience=5、batch16、两学习率0.001／0.0003、验证MAE选模**。300个候选共记录2816个epoch：287个按patience自然早停，13个达到20轮上限但尚未耗尽patience，其中6个在第20轮仍刷新最佳验证MAE。13指候选数量。15个方法—视图组合、逐候选状态和完整曲线见`audit300/`。

13个延长对象按全部300条已有验证历史中的“完整20轮且stale<5”统一筛选，覆盖12个逻辑单元；名单没有使用测试分数，也没有只保留旧HPO选中的候选。补充方案保持原种子、原学习率、样本与划分，重新初始化，改为单候选最多100轮／patience5，先只执行TRAIN／VAL。旧best权重缺少Adam和RNG，不能作为无缝续训来源。

这次延长确认首例在第24轮满足既定停止规则，额外4轮没有改善最佳验证分数。前20轮完全一致是该次记录的实测结果。验证MAE属于选模数据上的指标，不作为测试性能，也不据此宣称新模型优于旧模型。

这些DTA结果属于**作者架构在共同PPIKB数据上的预算受控适配重训**。原论文的Davis／KIBA数据、主要训练预算和选模协议另有差异，详见`audit300/REPORT.zh-CN.md`。DGDTA实际使用MSE，没有名为“CL”的对比预训练。五个作者原子特征仍缺手性编码，蛋白prefix截断仍保留；效应任务为差值损失适配，metadata-silver配对不等于同条件亲和力金标准。

`source/`附本项目自写的验证入口、完整epoch状态生产者、固定名单守门和13份配置，均保留实际冻结字节与SHA。没有重发作者NN、论文全文PDF、原始测量行／序列或新权重。代码按原工程相对目录使用，依赖、作者模型及数据需要沿既有公开资源获取流程恢复；源文件公开本身不构成可直接运行的独立软件包。

新完整epoch状态保存Adam、模型／BN、RNG和游标，首例已实际写出文件及SHA。本次独审没有反序列化内部Adam／RNG／BN值，resume消费者仍未实现；checkpoint和JSON收据是两个原子替换，未来恢复需交叉核验。新约77MB权重／state留在本地，本包不上传它们。

`logs/`包含24轮科学日志、训练stdout及完整stderr的确定性gzip。85,663,793字节stderr原件留在Ubuntu自有目录，仅压缩脱敏副本进入本包；962,510行完整保留，3处私有环境前缀替换，源码警告和行号保留。`EVIDENCE-INDEX.json`与压缩收据记录原件SHA、公开副本SHA及替换规则。未公开他人进程表、机器身份或大检查点。

这一个验证补充候选不增加既有1050 main或100 known-source supplement的计数，也不补作新的10种子选中面板。其他原生方法的正式进度保持其独立公开快照，本包没有新增相关完成声明。
