# 非标准肽亲和力基准数据协议

本目录由原始 PPIKB 和既有逐行残基审计派生，原始数据、历史模型及历史结果均未更改。只保留 Kd 精确观测，主队列非标准肽 2,099 行，标准残基对照 7,520 行，总计 9,619 行。标准残基不等于化学上完全无修饰；封端、环化、连接体与标签单独保留。

主数据为 `observations-with-audit.jsonl`，含完整原始观测与审计。`model-observations.jsonl` 是模型接口，`pKd` 原样继承 `-log10(Kd/M)`，输入为分子 SMILES 和靶标数据库参考序列。实际实验构建体序列均未认证，不将本基准写成实际构建体预测。

互斥评价层：非蛋白源/D/骨架 723、PTM 1,002、二者混合 268、其他非标准 106、标准对照 7,520。细分子类和附加未知化学组分仍保留。不能把混合类同时加进两个主分层而导致重复计数。

## 划分

`label-free-grouping-input.jsonl` 和 `label-free-study-aliases.jsonl` 不含数值亲和力。划分先于模型拟合，所有模型和训练种子共用同一份分区，种子 0–9 只改变训练随机性。

来源与肽依赖冷面板将以下关系做传递连通分量：原始 study id、规范化 DOI/PMID/题名别名、精确含立体分子图、去立体分子图、相同原始肽母体表示、提供的 parent series、长度至少 5 的同长度单替换邻居，以及 Morgan radius2/2048bit/无立体指纹 Tanimoto≥0.8 邻居。没有为了凑比例拆开组件。全部研究元数据仍是数据库证据，不冒称已逐篇认证。

当前实际分区 train 7,540 / validation 1,040 / test 1,039，最大组件 7,540 行，占78.39%，无法恰好按70/15/15切分。非标准行对应1,548 / 248 / 303。测试303行分为PTM158、非蛋白源/D/骨架100、混合39、其他6；标准测试736行。

靶标面板用既有 Bio.Align 1.85 C实现做所有参考序列对比较。声明身份率为匹配残基数/非gap成对列数；两方覆盖率为非gap成对列数/各自全长，阈值分别0.30和0.80。局部BLOSUM62，gap open=-10，extend=-0.5，固定取首个最优对齐；增加短端≥40 aa的精确域包含边，以及五个作者模型共同采用的靶标前1000残基等价边。长度与成分预排除均是该定义下不可能满足阈值的必要条件，不用可能漏检的kmer近邻预筛。只声明此参考序列相似度和精确包含约束，不能称为普适蛋白家族认证。全对比较已在Node23完成：含22条独立外源参考序列，共1,433条序列、1,025,797对、1,172条阳性边，8CPU耗时277.68秒，无GPU。靶标面板实际6733/1443/1443，NC对应1409/358/332；定义内参考同源边与前1000残基等价跨分区均为0。

双冷图最大组件8,948行，占93.02%，只作可行性诊断，不作为本轮主表。每个面板的限制分别报告：来源/肽冷允许靶标相近；靶标冷允许来源/肽相近。

本轮发现60个相同含立体分子图同时收到非标准与标准残基注释，涉及357条NC和251条标准观测。没有更改任何一方化学身份；主结果明确称annotation-stratified，并以`derived-quality-flags.jsonl`标记全部608行，强制在保存的同一批测试预测上另报排除这些行的敏感性结果。2,099是观测数，对应990种含立体分子图和1,212个分子图—参考靶标组合，不能写成2,099个独立分子。

## 执行与验证

`prepare_inputs.py` 准备原始完整档案与无标签分组输入；`remote_label_free_groups.py` 做有界纯CPU分子图和邻居计算；`assemble_split_proposal.py` 建图与确定性划分；`export_flat_model_view.py` 导出平铺模型接口；`test_split_protocol.py` 验证计数、资格、顺序不变性、输入哈希与组件隔离。

MMseqs2只做了只读入口探测。收到资源卡禁止执行信息后，在尚未调用计算前停止编排父进程并移除执行分支。RDKit计算正常终止，后续靶标比较使用允许的普通Bio.Align实现。没有GPU任务、模型拟合或原文单位调查。

主协调者已采用NC_only主训练与standard_only对照，两个cold面板；本轮不做pooled混合训练。此数据目录不启动训练。测试和外部标签不参与调参、选架构、提前停止或决定划分。测试报告按10个种子保留逐样本预测、超参数、检查点、指标和均值/样本标准差。`frozen-v1/manifest.json`出现后才是最终入口，候选目录不代替冻结清单。最终输入`inputs.jsonl`与标签`labels.jsonl`分离，所有分区及敏感性行号用`record_id`关联。
