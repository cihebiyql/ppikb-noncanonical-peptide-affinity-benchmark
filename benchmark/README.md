# PPIKB非标准肽亲和力基准

当前正在执行新共同数据基准，真实进度见 `STATUS.json`。旧基准和本轮smoke均不计入最终十种子训练结果。

## 冻结任务

- 非标准残基注释组2099条；同质量规则标准残基对照7520条，端点均为pKd。
- 五篇已发表模型：GraphDTA-GIN、MGraphDTA、DGDTA-CL、DeepNC-GEN、GS-DTA。原为分子—蛋白亲和力模型，本轮按作者实现迁移到肽—蛋白；不是原论文全套实验复现。
- 两组固定冷划分；各模型分别训练NC_only和standard_only，各用本类别验证集选优。
- 每单元种子0–9、两组预声明学习率、最大20轮、patience5。共400候选拟合、200次最终选择。
- 全部200个选择冻结后才统一读取测试/外部标签评分；当前正式过程不做创新模型。

## 数据与方法边界

标准/非标准化学注释与分子图有608行冲突（357非标准＋251标准）。名册和原标签保留，测试预测另按预先冻结名单重算排除敏感性；分层结果反映数据库注释组。

非天然/D/骨架、PTM、混合、其他非标准分别报告。五个图方法原始特征存在手性盲区；分子图完整保留，蛋白采用作者1000或1200 aa前缀，逐行保存覆盖率。必要实现修复和原文/代码差异已单独列出。

外部冻结75个可推理PTM记录（SH2 45＋Kliche30），其中67主评价、8条件性敏感性；来源及化学独立性对PPIKB全21845审计通过，参考靶标冷仅2条。另已接受独立来源及声明化学冷的13条补充诊断（非天然/D/骨架8＋标准对照5）：真实目标为单克隆IgG1整体2H2L，模型仅用有权威来源的449aa重链参考，属于靶标相关的参考视图，单独报告、不混入75主集或声称整抗体构建体验证。两组都在所有选择冻结后评分。
